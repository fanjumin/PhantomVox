# PhantomVox AI — 产品愿景报告 v0.2

## 一句话定位

**专业音视频创作 + AI Agent 深度集成** — 让创作者用自然语言驱动达芬奇级的生产力。

---

## 核心能力矩阵

### 1. 达芬奇级专业编辑（DaVinci-Inspired）

| 模块 | 功能 |
|------|------|
| **多轨时间线** | 音视频轨道自由编排，支持 clip 切割/拖动/特效叠加 |
| **专业调色** | AI 辅助色彩分级、LUT 管理、色轮调整 |
| **Fairlight 音频工作区** | 多通道混音、均衡器(EQ)、动态处理、Sidechain |
| **专业输出** | 多格式渲染、自定义分辨率/码率/帧率 |

**差异化**：不是复刻达芬奇 UI，而是提供**核心专业能力 + AI 简化操作**。

---

### 2. AI 音频工坊（Audio Workshop）

声音工坊 + 音乐工坊合并，一个完整的音频创作中心：

| 能力 | 说明 |
|------|------|
| **语音克隆** | 从 30 秒样本克隆任意人声，支持情感/语调控制 |
| **TTS（文本转语音）** | 多语言、多音色，可调节语速/音高/停顿 |
| **语音合成** | 为视频生成旁白、配音、对白 |
| **文生音乐** | 输入描述（"忧郁的钢琴+弦乐背景"）生成 BGM |
| **风格控制** | 古典/电子/流行/影视/游戏/氛围感，精确到秒自动匹配时间线 |
| **音频修复** | 降噪、去回声、音量均衡、动态压缩 |
| **自动适配** | 根据视频情绪/节奏自动推荐音乐和音效 |

---

### 3. AI 视觉工坊（Visual Workshop）

#### 3.1 图像/视频生成

| 能力 | 说明 |
|------|------|
| **文生图/视频** | 根据描述生成素材，直接入轨时间线 |
| **AI 扩图/补帧** | 图像扩展、视频慢动作补帧 |
| **AI 去背景/物体移除** | 一键去背，智能物体消除 |

#### 3.2 AI 图像修复（Image Restoration）

独立模块，对标主流 AI 修复工具的全部能力：

| 能力 | 说明 |
|------|------|
| **旧照片修复** | 去划痕、折痕、污渍、霉斑 |
| **AI 上色** | 黑白照片智能上色，支持指定调色风格 |
| **超分辨率** | 低清图 → 4K/8K，人脸细节增强 |
| **去噪/锐化** | 老照片/暗光照片降噪增强 |
| **人脸修复** | 老照片中模糊人脸重建清晰五官 |
| **去压缩伪影** | 修复 JPEG 压缩导致的块状失真 |
| **视频帧修复** | 对视频每一帧进行修复，提升整体画质 |
| **生成图像后调整** | 对 AI 生成的图像进行二次精修 |

### 4. 多智能体系统（Multi-Agent）

**这不是后台的隐形调度，而是一个独立的操作界面**，是 PhantomVox 的核心交互入口。

#### 4.1 界面布局

```
┌──────────────────────────────────────────────┐
│  多智能体控制中心                              │
├──────────────────────────────────────────────┤
│  [思维导图] ← 核心                             │
│                                              │
│        ┌─ AI聊天 ─┐                           │
│        │           │                           │
│  ┌─────┴─ 深度思考 ─┴─────┐                    │
│  │        图像生成         │                    │
│  │        代码生成         │                    │
│  └─────────────────────────┘                    │
│                                              │
│  ┌─ 多智能体矩阵 ────────────────────────┐     │
│  │ Director │ Editor │ Audio │ Music     │     │
│  │ Visual   │ Color  │ Code   │ Restore  │     │
│  └────────────────────────────────────────┘     │
└──────────────────────────────────────────────┘
```

#### 4.2 四大子面板

| 面板 | 功能 |
|------|------|
| **AI 聊天** | 自然语言交互入口，用户说需求，系统自动分解执行 |
| **深度思考** | 复杂任务的分步推理过程可视化，用户可以查看/干预 AI 的思考链路 |
| **图像生成** | 直接在此面板内完成文生图、图生图，拖入时间线 |
| **代码生成** | **会话式编程** — 用自然语言编写特效、转场、调色参数、音乐参数等，代码直达应用模块执行 |

**代码生成示例：**

```
用户说："创建一个从左到右的划像转场，持续0.5秒"
→ 系统自动生成对应代码/配置
→ 一键应用到时间线当前轨道

用户说："在这段视频上叠加 VHS 复古特效，加噪点30%"
→ 代码生成 → 特效即刻预览
```

#### 4.3 核心：思维导图（Mind Map）

思维导图是整个多智能体模块的核心，它：
- **可视化创作流程** — 用户可以看到 AI 如何分解任务、串联步骤
- **可编辑** — 用户可以拖拽修改思维导图中的节点
- **可回溯** — 任何步骤都可以回退到上一步重新选择
- **可分支** — 一个需求可以生成多个方案分支供用户选择

```
示例：用户说"制作一个3分钟产品宣传片"

                    ┌→ 语音克隆(A) → 旁白生成
                    │
  产品宣传片 ──┬──→ 音乐生成(B) ─→ 选择风格
              │       │
              │       └→ 匹配时间线
              │
              ├──→ 素材准备(C) ─→ 文生背景素材
              │       │
              │       └→ 旧照修复(产品图)
              │
              ├──→ 时间线编排(D) → Director 调度
              │
              └──→ 代码生成(E) → 自定义转场特效
```

#### 4.4 多智能体矩阵（Agent Matrix）

所有可用的 Agent 统一展示，用户可手动激活/禁用、查看状态、分配任务：

| Agent | 角色 | 对接模块 |
|-------|------|---------|
| **Director Agent** | 导演，分解任务、协调调度 | 全局 |
| **Editor Agent** | 剪辑师，时间线操作 | 达芬奇引擎 |
| **Audio Agent** | 音频师，语音+TTS+混音 | 音频工坊 |
| **Music Agent** | 作曲家，音乐生成 | 音频工坊 |
| **Visual Agent** | 视觉师，图像/视频生成 | 视觉工坊 |
| **Color Agent** | 调色师，色彩分级 | 达芬奇引擎 |
| **Restore Agent** | 修复师，旧照+视频修复 | 视觉工坊 |
| **Code Agent** | 程序员，会话式代码生成 | 全模块参数 |
